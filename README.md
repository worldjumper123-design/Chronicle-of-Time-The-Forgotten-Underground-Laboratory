《時空遺痕》遊戲簡介
歡迎來到 《時空遺痕》，這是一款結合復古科幻與懸疑解謎的網頁冒險遊戲。

在第 03 區被遺忘的地下研究室中，時間彷彿停格在 1984 年至 2024 年之間。這裡的房間依然在暗中運轉，卻早已沒有人承認它的存在。玩家將扮演一名探險者，踏入這個充滿未知與時間異變的地下設施。

核心特色
沉浸式黑金視覺：以獨特的復古終端機與檔案封印美學，帶領玩家一步步深入廢棄的研究紀錄。

沉浸式身份驗證：支援個人化探險者名稱登記與安全授權流程，打造真實的實驗室潛入體驗。

豐富的謎題挑戰：探索三個封閉的實驗室房間，破解四個錯綜複雜的數位謎題。

雙人連線模式：支援雙人協同檔案檢索，與同伴一同在時間序列中尋找出口。

房間仍在運轉，準備好揭開被掩蓋的時空真相了嗎？
